Privacy Policy

Last updated: June 12, 2026

MoneyPrinter Creator Assistant is a private desktop application used only by its owner to manage the owner's About Everything YouTube channel.

Data accessed

With the owner's explicit Google OAuth authorization, the application may access channel identity, upload creator-owned videos, manage subtitles and localized metadata, and read channel analytics.

Data use and sharing

Data is used only to perform requested channel-management tasks and improve the owner's original content. The application does not sell, rent, share, or expose Google user data to third parties. It does not automate likes, comments, subscriptions, or other engagement.

Storage and security

OAuth credentials and generated files are stored locally on the owner's computer and are not published in this repository. Access can be revoked at any time through the Google Account permissions page.

Deletion

The owner may delete local credentials and application data at any time. Revoking Google access prevents future API access.
